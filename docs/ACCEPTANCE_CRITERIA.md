## AC-01: 免責フッター全ページ表示

- **条件**: 全ページに、CONSTITUTION.md 第4条の免責文が一字一句変更なく表示されること
- **実装**: `app/layout.tsx` で `<Footer />` コンポーネントを常時レンダリングする
- **確認**: `npm run check` で Footer コンポーネントが layout.tsx に含まれることを検証する

免責文（固定・変更禁止）：
> 本ツールはBASIC-Phに基づく自己理解・自己対処の可視化を目的としており、医学的・心理学的な診断を行うものではありません。結果は「あなたの対処のあり方の傾向」を示す参考情報であり、優劣・正常異常の判定を含みません。心身の不調や専門的なサポートが必要と感じる場合は、医療機関や専門家にご相談ください。

## AC-02: 結果画面の3点表示

- **条件**: 結果画面（/result）で6チャンネルそれぞれに以下の3点を表示すること
  1. 役に立ちやすい場面（`usefulScene`）
  2. 行き過ぎたときに起こりやすい疲れ方（`overuseRisk`）
  3. 今日できる1分ワーク（`oneMinuteWork`）
- **実装**: `constants/channels.ts` の内容をそのまま使用する（独自生成・書き換え禁止）

## AC-03: 非断定文体

- **条件**: 結果画面・UI文言において断定表現を使用しないこと
- **基本形**: 「〜かもしれません」「〜することがあります」「〜と感じる人もいます」
- **禁止**: 「あなたは〜だ」「必ず〜」「〜するべき」「〜しなければならない」
